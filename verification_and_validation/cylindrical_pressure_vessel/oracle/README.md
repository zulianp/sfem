# Oracle Data

`radial_stress.csv` and `hoop_stress.csv` are the analytical Cauchy-stress profiles published for the cylindrical pressure-vessel benchmark. They were transcribed from `radial_stress.dat` and `hoop_stress.dat` in the solids4foam tutorials benchmark data repository at commit `6917f439243d7d782d42aacf1227b12b2300d5b2`.
