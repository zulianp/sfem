# Two-dimensional hyperelastic modes

This case prescribes finite affine uniaxial extension, simple shear, and uniform
dilation on generated TRI3 and QUAD4 meshes. Independent formulas evaluate each
model's strain energy and first Piola stress. Modified Mooney-Rivlin uses a 3D
plane-strain embedding with `F33 = 1`. All quantities are nondimensional.
