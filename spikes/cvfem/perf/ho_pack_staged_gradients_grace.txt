# THE NODAL VELOCITY GRADIENTS STAGED INTO THE PACK: measured on Grace, kept.
#
# The change. The packed higher-order sweeps -- the residual, the exact Jacobian action on both of
# its entry points, and the pack-coloured action that passes empty packs -- gathered the state's
# and the direction's nodal velocity gradients from the global arrays through the STANDARD
# connectivity: eight global node ids per element on top of the pack's own indices, and each
# node's 72-byte row re-read once per adjacent element. Every other field the packed sweep reads
# was already staged once per pack. Now these two are too: cvfem_hex8_fill_pack_ugrad copies the
# owned range as a stream and the ghosts through the pack's ghost list into scratch slots 14 and
# 15, cvfem_hex8_gather_ugrad_from_pack gathers lane-major through the 16-bit pack indices, and
# no packed sweep takes the standard connectivity any more. The storage type (double, or float
# under SFEM_GRAD_PRECISION=single) converts at the fill.
#
# Exactness: unchanged on every oracle. Packed against atomic 7e-18 to 1e-17; the exact Jacobian
# against a finite difference 1.625e-10 unlimited and 1.175e-03 / 2.332e-03 limited on 0.38% of
# dofs, 1.48e-10 on the warped mesh; f32 storage against f64 6e-10 residual, 7e-09 Jacobian.
#
# jobs/ab_refactor.sbatch, job 5004447 (nid006555): this change alone, against the tree before it.
#
#   residual_packed_ho_unlim     1019.0 -> 1031.8   +1.3%

#   residual_packed_ho_dm         810.3 ->  816.0   +0.7%

#   jac_action_packed_ho_venk     309.5 ->  309.0   -0.2%

# (nid006557): every one of the 23 rows within 1.2%, PASSED.

# WHAT THIS SAYS. The global re-reads were real traffic but hit in cache often enough that

# the format says it is -- no standard connectivity read anywhere in it -- which the paper states.
